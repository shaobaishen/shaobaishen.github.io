隱私權政策

本政策適用於 shaobaishen 維護的 Hermes Agent 個人台股研究排程及本說明網站，生效日期為 2026 年 11 月 9 日。

存取哪些 Google 資料

本部署申請 Google 試算表讀寫權限（spreadsheets）及雲端硬碟檔案基本資訊唯讀權限（drive.metadata.readonly）。程式依設定存取指定的研究紀錄表，讀取帳號與檔案資訊來核對目的地，新增研究結果並更新後續追蹤欄位。本部署的 Google 授權不包含 Gmail、日曆或通訊錄。

資料用途與分享

Google 資料僅用於使用者指定的研究紀錄保存、讀回驗證與追蹤。研究摘要依使用者設定經 LINE 傳送至其指定接收對象；公開行情與新聞由 AI 服務協助分析。OAuth 憑證不納入研究提示或對外訊息。Google 使用者資料不出售，不用於廣告，也不用於建立或訓練通用 AI／機器學習模型。

本程式對 Google API 資料的使用與轉移遵循 Google API Services User Data Policy，包括 Limited Use 要求。

儲存與保護

OAuth 憑證與本機研究紀錄保存在使用者管理的 Mac。憑證檔案限制為該使用者可讀寫，對 Google 的請求使用 HTTPS。試算表資料由 Google 儲存；LINE 訊息由 LINE 處理。紀錄保留供追蹤與防止重複通知，直到使用者自行刪除或要求維護者移除。

撤銷與刪除

使用者可從 Google 帳戶連線設定撤銷 Hermes Agent 的存取權，並在本機停止排程、移除憑證及紀錄。Google 試算表與 LINE 訊息可在各服務中自行管理；撤銷授權不會自動刪除既有紀錄。

本公開網站

本站僅提供靜態說明，不設註冊表單、追蹤程式或廣告。網站由 GitHub Pages 提供，主機服務可能依其政策處理一般連線資訊。本站不公開私人試算表內容、OAuth 憑證或 LINE 收件者資訊。

聯絡與更新

如需詢問或刪除協助，可透過網站專案的問題回報頁聯絡維護者；公開留言請勿包含密碼、憑證或私人資料。資料用途有變更時，將更新本頁與生效日期。
